# King's Dilemma 개인 보유물 조사 메모

조사일: 2026-05-07

## 결론

이번 단계에서 구현할 개인 보유물은 아래로 제한한다.

- 재화(코인): 협상과 거래에 쓰이며 개인이 보유한다.
- 권력 토큰: 투표 영향력으로 쓰이며 개인이 보유한다.
- 위신/갈망 점수: 캠페인 동안 가문 화면에 누적되는 개인 성향 점수다.
- 자원 메모: 영향력, 부, 사기, 복지, 지식은 원칙적으로 공용 보드의 5개 자원 마커다. 아직 공용 보드판을 구현하지 않으므로, 이번 버전에서는 각 플레이어가 자기 화면에서 참고용으로 수동 기록하는 값으로만 둔다.

따라서 앱의 서버 저장 대상은 "인증된 좌석의 개인 인벤토리"이고, 다른 좌석의 값은 내려주지 않는다.

## 근거

- GIGAZINE 플레이 리포트는 초기 세팅에서 각 플레이어에게 권력 토큰 8개와 코인 10개를 지급하고, 이 토큰들이 가문 화면 뒤에 숨겨지는 중요한 자산이라고 설명한다. 같은 글은 공용 보드에 놓이는 자원 토큰을 영향력, 경제력/부, 활력/사기, 복지, 문명/지식 계열의 5개 마커로 설명한다.  
  출처: https://gigazine.net/gsc_news/en/20210109-kings-dilemma/

- Meople's Magazine의 스포일러 없는 리뷰는 투표 때 Power Tokens를 사용하고, 협상에서 돈을 제안할 수 있으며, 딜레마 결과가 5개 왕국 자원(Influence, Wealth, Morale, Welfare, Knowledge)을 조정한다고 정리한다. 또한 게임 종료 후 Prestige와 Crave를 기록한다고 설명한다.  
  출처: https://www.meoplesmagazine.com/2020/06/09/the-kings-dilemma/

- Spielregeln.de의 구성품 목록은 65개 권력 마커, 72개 코인, 5개 자원 마커를 별도 구성품으로 정리한다. 세팅 설명에서도 각 플레이어가 가문 화면을 고르고 이름을 적으며, 공용 보드에는 자원/안정성 관련 마커가 놓인다고 설명한다.  
  출처: https://www.spielregeln.de/the-kings-dilemma.html

- Twenty Sided의 제품 정보도 구성품으로 72 Coin Tokens, 65 Power Tokens, 5 Resource Markers를 구분한다. 이 구분은 코인/권력 토큰은 개인 보유물, 자원 마커는 보드 상태라는 모델링 판단과 맞다.  
  출처: https://twentysidedstore.com/products/the-kings-dilemma

- 원격 플레이용 커뮤니티 시트 사례에서는 각 플레이어가 개인 페이지에서 보유물과 코인/영향력을 수동 갱신해야 한다고 안내한다. 이번 구현의 "수동 조정 후 일괄 저장" 방식과 같은 방향이다.  
  출처: https://www.reddit.com/r/boardgames/comments/fij9na/i_made_a_google_sheets_setup_to_play_the_kings/

## 구현 결정

- 기본값은 첫 세팅 기준인 코인 10, 권력 토큰 8, 위신 0, 갈망 0으로 둔다.
- 자원 메모는 보드 트랙 행을 기록하기 좋게 0-17 사이 정수로 제한한다. 0은 아직 기록하지 않았거나 중앙/초기값을 앱에서 확정하지 않았다는 의미로 사용할 수 있다.
- 모든 값은 화면에서 화살표 버튼으로만 1씩 올리거나 내린다.
- 값 변경 중에는 서버 요청을 보내지 않는다. `일괄 저장` 버튼을 눌렀을 때만 `/api/agenda`의 `saveInventory` 액션으로 저장한다.
- 저장하지 않은 변경사항이 있으면 브라우저 종료/새로고침에 `beforeunload` 경고를 걸고, 나가기/초기화/되돌리기에도 확인을 거친다.
- 저장 전 드래프트는 `sessionStorage`에만 임시 보관한다. 창이 실수로 닫혀도 같은 탭 세션에서 복구될 수 있고, Netlify 요청은 발생하지 않는다.
